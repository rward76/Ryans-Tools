    The rules
    ω₂ / ω₁ = N₁ / N₂gear mesh, teeth
    ω₂ / ω₁ = D₁ / D₂belt, diameters
    τ₂ = τ₁ · (N₂/N₁) · ηtorque trades for speed
    P = τ · ωwatts = N·m × rad/s

    Each mesh reverses direction. An open belt keeps it; a crossed belt reverses it. Gears here use module 2, so pitch diameter = 2 mm × teeth.
