    Torque is what each part can deliver if it carries the whole load. A differential is the exception: it always splits torque equally between its outputs.

    The rules
    ω₂ / ω₁ = N₁ / N₂gear mesh, teeth
    ω₂ / ω₁ = D₁ / D₂belt, diameters
    ω_wheel / ω_worm = starts / Nworm drive
    v = ω · r, F = τ / rrack and pinion
    ω_s + k·ω_r = (1+k)·ω_cplanetary, k = Z_ring / Z_sun
    ω_L + ω_R = 2·ω_cdifferential
    P = τ · ω = F · vpower

    Each external mesh reverses direction; open belts keep it, crossed belts reverse it. Gears use module 2, so pitch diameter = 2 mm × teeth and the rack's tooth pitch is 2π mm.
