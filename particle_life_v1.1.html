Matrix symmetry—

Collective drift compares the net momentum of all particles to their total motion. Symmetric rules obey "action = reaction," so drift stays near 0%. Lopsided rules let clumps push themselves along.

How it works

Every particle is a hard ball, like a billiard ball: balls bounce off each other and can never overlap. Each ball also looks at its neighbors within rmax, and the matrix decides how it reacts. A positive number pulls the row type toward the column type; a negative one pushes it away, hardest up close and fading with distance. Inside the core (β·rmax) every pair pushes apart a little. Friction slowly bleeds off speed.

The rules don't have to be fair: red can chase blue while blue runs from red. That broken symmetry is what makes cells, worms and swarms appear from a handful of numbers.

  • Set one type to attract itself (+1) and ignore everything else. What shape forms?
  • Load Symmetric, then Chase ring. Watch the drift readout.
  • Shrink the core size β. When do clusters collapse into crystals?
  • Set every rule to −1. Do the balls spread out evenly?
