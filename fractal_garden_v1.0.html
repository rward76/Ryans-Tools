Box counting: cover the drawing with grids of boxes of size ε, count the boxes N(ε) that touch it. The slope of log N against log(1/ε) estimates the fractal dimension — 1 for a smooth line, 2 for something that fills an area. Finite iterations always come out a bit low.

About L-systems

In 1968 biologist Aristid Lindenmayer described plant growth with a rewriting game: start with a short string (the axiom) and, every generation, replace each symbol using the rules. A tiny rule set, repeated, builds enormous self-similar structure.

The string is then read by a turtle that walks, turns, and remembers branch points. Brackets make branches; without them you get a single winding curve such as the Koch snowflake or dragon curve.
